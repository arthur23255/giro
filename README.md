# GIRO

**Organize contatos, lembretes e próximos passos de venda.**

O GIRO é um app web gratuito para quem vende por conta própria e quer acompanhar conversas sem depender de uma planilha.

- [Conheça o GIRO](https://arthur23255.github.io/giro/divulgue.html)
- [Abrir o app](https://arthur23255.github.io/giro/)

## O que dá para fazer

- Cadastrar, editar, buscar, filtrar e remover contatos.
- Registrar a etapa, o assunto e a data para retomar.
- Concluir ou adiar lembretes e ver um resumo do dia.
- Preparar rascunhos de mensagem por etapa, assunto e tom; revisar e abrir no WhatsApp.
- Baixar uma cópia dos dados e restaurá-la depois.
- Instalar como app web e usar offline após a primeira abertura com internet.

## Privacidade e limites

Os dados ficam no armazenamento local do navegador. Não há conta, sincronização entre aparelhos, acesso do criador aos contatos ou avisos de lembretes com o app fechado. Os rascunhos são criados por regras locais, sem integração com uma IA online. Revise toda mensagem antes de enviar.
